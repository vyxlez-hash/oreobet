# OREOBET drop-in frontend

This archive contains the generated `src/` tree for the existing Vite/React/TypeScript project.

Copy the contents of `src/` into:

`project/src/`

Important:
- This is a frontend/demo implementation.
- Financial balances, deposits, withdrawals, admin permissions, CAPTCHA verification, and game outcomes must be connected to authenticated server-side APIs before production use.
- The deposit addresses in the UI are placeholders until connected to the admin-controlled backend.
- Put your real `logo.png` at `project/public/logo.png`.
- The game animations are visual UI; authoritative game outcomes should come from the backend.
